# Portfolio media

These previews show existing work rather than illustrative placeholders.

- `ims.webp`: capture of the inventory application's actual dashboard. Company branding is replaced with “Inventory Management”; all 36 assets and the demo account are synthetic sample data. No production inventory or user records are included.
- `tcg.webp`: capture of the Vegas TCG Exchange event website.
- `zeal.webp`: capture of the Project Zeal home page.
- `chorrona.mp4` / `.webp`: front idle animation and first-frame poster, encoded from the existing `chorrona-idle-front-832x576.gif` (832 × 576).
- `gatoru.mp4` / `.webp`: standalone floating character and first-frame poster, encoded from the existing `Gatoru_Two_Tails_Blue_Pulse_60fps.mp4` (640-pixel-wide preview).

Videos are muted, loop only while visible and scenery is enabled, and pause when the document is hidden. Posters remain visible when motion is off. The time-of-day banner remains live; the home-page screenshot is a fixed project capture.
